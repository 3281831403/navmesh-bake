# navmesh-bake

## 题面

烘焙一张大地图时，导航网格一上就出错：合并共面三角形时角度阈值把度当弧度用，30 度被当成 30 弧度；边界内缩按顶点法线而不是边法线，凹角处自交；台阶高度与最大坡度共用同一阈值，0.4m 台阶被当成可行走斜坡；坡度用面中心高度差近似，陡坡被判成可行走；孤岛不标记 island id，寻路跨岛；加动态障碍后不重算连通性，路径穿墙；多代理半径只取第一个代理，大体积代理卡住；cost 允缺失或负值，A* 出现负权；批量烘焙部分失败留半成品，调用方无法判断；烘焙后法线不重算，朝下的面被当可行走。navmesh/bake.py 是核心，tests/test_bake.py 15个红。要修的是：角度阈值统一用度并在比较时换算为弧度；边界改按边法线内缩并正确处理凹角；台阶高度与最大坡度分开判定；坡度严格按面法线与竖直方向夹角计算；为每个孤岛写入稳定 island id 并禁止跨岛寻路；动态障碍落地后重算连通性与 island 归属；处理全部代理半径而不只第一个；cost 必须完整且为正值；批量烘焙任一失败整体回滚；烘焙后重算法线并拒绝朝下面。

## 复现

```bash
python -m pytest tests -q
```

预期最后一行：

```text
15 failed
```

## 约束

- 只使用 Python 标准库与 pytest，离线运行，不使用随机数，不调用 sleep。
- `tests/test_bake.py` 不可修改；需要让其中的 15 个测试全部通过。
- `navmesh/bake.py` 中 8 个函数目前只有契约和 `NotImplementedError` 桩，角度参数一律以度为单位，数值比较容差为 `1e-9`。
